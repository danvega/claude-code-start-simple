# Claude Code: Start Simple, Scale Smart

If your feed is full of developers orchestrating five agents from the gym while you're still asking Claude to write a test, this talk is for you. Claude Code is powerful. Maybe too powerful. With so many features, it's hard to know where to start and easy to feel like you're already behind.

In this session, I'll show you how I actually use Claude Code day to day. We'll start with the fundamentals that deliver immediate value: the vocabulary that matters, picking a surface, and setting up permissions so you can trust the tool. Then we'll build up to the features that make Claude Code truly yours. You'll teach it your project with CLAUDE.md, skills, and MCP, then scale up with subagents, hooks, and goals.

You don't need to learn everything at once. You need to know what matters first and what to add as you grow. By the end, you'll have a clear path from beginner to power user and proof that you were never behind to begin with.
